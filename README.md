# VMedia Sales Console — Ultimate Edition

## Overview
A production-grade, feature-rich web assistant designed for high-efficiency sales operations. Built with modern HTML5, CSS3 (variables, custom dark/light themes, smooth animations), and Vanilla JavaScript to streamline call flows, speed sizing, tax calculations, and script referencing.

## Key Features
* **Call Management & Timer:** Built-in interactive 3-minute call timer with audio beeps and session counters tracking daily customer logs via `localStorage`.
* **Dynamic Speed Calculator:** Automatically calculates recommended internet speeds based on the number of connected household devices.
* **Live Tax Calculator:** Real-time provincial tax rate application and total calculation across Canadian provinces.
* **Quick Scripts & Clipboard Utilities:** One-tap copying for customer details, service info, and compliance scripts to eliminate tab-switching mid-call.
* **Theme Customization:** Seamless light and dark mode toggling with persistent state retention.
