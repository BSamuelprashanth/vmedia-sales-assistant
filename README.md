# ⚡ VMedia Sales Console — Ultimate Edition

> A production-grade, feature-rich web assistant engineered for high-efficiency sales operations. Designed to eliminate tab-switching mid-call by centralizing customer intake, dynamic speed sizing, provincial tax calculations, call duration tracking, and compliance scripting into a single-page interface.

---

## 🌟 Overview

The **VMedia Sales Console** is a high-performance client-side application built for customer care and sales representatives. It bridges the gap between fast-paced customer interactions and rigorous data collection accuracy, featuring automated clipboard utilities, live provincial tax arithmetic, interactive call timers, and state persistence.

---

## 🚀 Key Features

* **⏱️ Precision Call Timer & Audio Alerts:** Features an integrated 3-minute interactive call countdown timer with custom web-audio frequency beeps at key milestones and automated session logging via `localStorage`.
* **⚡ Dynamic Speed Sizing Calculator:** Instantly estimates and recommends optimal internet speeds based on the number of connected household devices ($15 \text{ Mbps}$ per device multiplier).
* **🧮 Live Provincial Tax Calculator:** Real-time calculation of federal and provincial taxes (GST, PST, HST, QST) across all Canadian provinces and territories with instant rate updating.
* **📋 One-Tap Clipboard Automation:** Instant copy triggers for individual customer fields or a comprehensive multi-line text package for lightning-fast CRM data entry.
* **✓ Call Progress Checklist:** Interactive progress tracker ensuring compliance across mandatory disclosures (discovery, terms & conditions, 3-email overview, and closing).
* **📑 Quick Scripts Repository:** Built-in modal library providing one-tap copying for standard compliance scripts, payment instructions, and closing statements.
* **🌓 Persistent Theme Engine:** Fully responsive design system featuring smooth transitions between custom Light and Dark modes with automatic system preference detection and local storage retention.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Advanced CSS Variables, Flexbox/Grid, Custom Animations, Glassmorphism UI)
* **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, Web Audio API, LocalStorage API)
* **Design System:** Custom-built tokenized design system inspired by modern dashboard aesthetics with responsive layouts for varying viewports.
